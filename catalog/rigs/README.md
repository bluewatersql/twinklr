# Movement reference positions

`movement-reference-positions.json` is a current `RigPresetLibrary` for the synthetic
four-head preview (`MH1`–`MH4`), including the existing flick attribute. It supplies
concrete fan, narrow fan, wall-wash, scattered/chaos, audience/asymmetric, outward
mirror, rainbow arc, center-out, spotlight, crossed-X, tilt-bias, chevron, tunnel
and alternating aims used by the restored arrangements. The test helper verifies
this file against the synthetic reference rig.

These are explicit example degrees, not owner calibration or automatic placement.
Use these named presets with a fixture group only after authoring its actual safe
aims. Missing presets fail template admission. The delivered show package contains
the matching complete synthetic profile/job and layout.
